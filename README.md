# NARA2 BIG DATA

ต้นแบบ Dashboard เชิงข้อมูลสำหรับสำนักงานเขตพื้นที่การศึกษาประถมศึกษานราธิวาส เขต 2

## ฟังก์ชันในต้นแบบ
- Dashboard KPI: 117 โรงเรียน, นักเรียน 25,610 คน, ครู 2,482 คน, บุคลากรเขต 74 คน
- จำนวนโรงเรียน 5 อำเภอ
- แนวโน้มนักเรียน ครู และบุคลากรย้อนหลัง 5 ปี
- วิเคราะห์จำนวนผู้เกษียณอายุราชการรายปี พ.ศ. 2569–2578
- แก้ไขข้อมูลเกษียณแบบสาธิตและบันทึกใน localStorage ของเบราว์เซอร์
- Responsive สำหรับ Desktop / Tablet / Mobile

> ข้อมูลผู้เกษียณและแนวโน้มย้อนหลังในต้นแบบเป็นข้อมูลสาธิต ไม่ใช่ข้อมูลราชการจริง ต้องแทนที่ด้วยข้อมูลจริงก่อนใช้งานเชิงนโยบาย

## GitHub Pages
ไฟล์ `index.html`, `style.css` และ `app.js` เป็นเว็บ Static พร้อมเผยแพร่ผ่าน GitHub Pages ได้ทันที โดยตั้งค่าใน Repository > Settings > Pages > Deploy from a branch > `main` / `(root)`.

## ขั้นต่อไป
เวอร์ชันฐานข้อมูลจริงสามารถเชื่อม Supabase เพื่อเพิ่ม Authentication, สิทธิ์ผู้ใช้, ตารางโรงเรียน/นักเรียน/บุคลากร, Import Excel และการคำนวณปีเกษียณอัตโนมัติจากข้อมูลบุคลากร
